# 分析题：为什么正则化前必须 Z-score 标准化？不做的后果

Z-score 标准化：\(z_i=\frac{x_i-\bar{x}}{s_x}\)，使变量均值为 0，方差为 1。

### 原因

岭回归、Lasso 的正则化惩罚项直接惩罚回归系数\(\boldsymbol{\beta}\)，**系数大小和自变量量纲有关**。不同变量单位、量级不一样，不标准化时惩罚力度不公平。

### 不做标准化的后果

1. 惩罚不公平：量级小的变量系数更容易被压缩，变量重要性被量纲扭曲。
2. 超参数\(\lambda\)难以选取，结果不稳定。
3. 系数不能横向对比，无法判断变量相对重要性。
4. Lasso 变量筛选出错，错误剔除变量。
